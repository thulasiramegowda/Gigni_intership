### ⚡ Project 3 – Workflow Web App

A professional drag-and-drop workflow visualizer web application built with **React**.

This project is a complete, production-ready workflow builder that allows users to visually create, edit, connect, and inspect workflow nodes on an interactive canvas. It's designed to look and feel like a genuine developer/productivity tool.

**Key Features**
- 🎨 **Interactive Canvas**: Drag, drop, connect, and manage workflow nodes
- 📦 **8 Node Types**: Start, Input, API Request, AI Processing, Condition, Database, Output, End
- 📝 **Properties Panel**: Dynamic editing with real-time updates
- 📊 **JSON State Management**: Real-time workflow visualization
- 💾 **Local Persistence**: Auto-save with localStorage
- 📤 **Import/Export**: JSON workflow import and export
- ↩️ **Undo/Redo**: Full history with keyboard shortcuts (Ctrl+Z, Ctrl+Y)
- 🔍 **Zoom & Pan**: Canvas navigation controls
- ⌨️ **Keyboard Shortcuts**: Power user shortcuts
- 🎨 **Professional UI**: Dark theme with gradient accents

**Tech Stack**
- React 18.2.0
- React Flow 10.3.17
- UUID 9.0.0
- LocalStorage
- CSS3 (Custom styling)
