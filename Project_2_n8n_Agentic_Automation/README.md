# Project 2 - n8n Agentic Automation

## Overview

This project demonstrates an AI-powered automation workflow built using n8n.

The workflow accepts user input, processes it using an AI language model, generates relevant tags, and stores the processed information automatically.

---

## Features

- AI-powered content analysis
- Automatic tag generation
- Google Sheets integration
- Automated workflow execution
- Low-code AI automation

---

## Workflow

User Input
↓
n8n Workflow
↓
OpenAI Chat Model
↓
Generate Tags
↓
Store into Google Sheets
