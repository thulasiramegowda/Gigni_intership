### ⚡ Project 3 – Workflow Web App

An interactive drag-and-drop workflow builder developed using **React**.

The application provides a visual canvas where users can create, connect, edit, and inspect workflow nodes. It is designed to resemble a developer productivity tool, with a canvas for workflow construction and a panel for configuring individual nodes.

**Key Features**

- 🎨 **Interactive Canvas:** Drag, drop, connect, and manage workflow nodes.
- 📦 **8 Node Types:** Start, Input, API Request, AI Processing, Condition, Database, Output, and End.
- 📝 **Properties Panel:** Dynamically edit node configurations.
- 📊 **JSON State Management:** View the workflow structure in JSON format.
- 💾 **Local Persistence:** Automatically save workflow state using localStorage.
- 📤 **Import / Export:** Import and export workflow configurations in JSON format.
- ↩️ **Undo / Redo:** Track editing history with keyboard shortcuts.
- 🔍 **Zoom & Pan:** Navigate around the workflow canvas.
- ⌨️ **Keyboard Shortcuts:** Perform common actions efficiently.
- 🎨 **Professional UI:** Dark-themed interface with gradient accents.

**Tech Stack**

- React 18.2.0
- React Flow 10.3.17
- UUID 9.0.0
- JavaScript
- HTML5
- CSS3
- Browser LocalStorage

**Quick Start**

```bash
cd Project_3_Workflow_Web_App

npm install

npm start
```

**What I Explored**

- Building interactive interfaces using React.
- Working with node-based visual editors.
- Managing application state.
- Implementing drag-and-drop interactions.
- Working with JSON data structures.
- Implementing undo and redo functionality.
- Designing reusable and interactive components.
