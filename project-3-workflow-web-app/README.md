# Workflow Web App - Project 3

## 📋 Project Overview

A professional drag-and-drop workflow visualizer web application built with React. This tool allows users to visually create, edit, connect, and inspect workflow nodes on an interactive canvas.

**Gigni Internship Project 3**

## 🎯 Problem Statement

Develop a drag-and-drop workflow visualizer canvas in React that renders flowchart nodes, properties, and connects JSON states into a functional, professional-grade application suitable for internship verification.

## ✨ Features

### Core Functionality
- **Interactive Canvas**: Drag, drop, connect, and manage workflow nodes
- **Node Types**: Start, Input, API Request, AI Processing, Condition, Database, Output, End
- **Properties Panel**: Dynamic editing of node properties with immediate updates
- **JSON State Management**: Real-time workflow state representation
- **Persistence**: Auto-save to localStorage with manual save/load
- **Import/Export**: JSON workflow import and export functionality
- **Undo/Redo**: Full history management with keyboard shortcuts
- **Zoom & Pan**: Canvas navigation controls

### UI/UX
- Professional dark theme with gradient accents
- Clean, minimal design focused on functionality
- Responsive layout for different screen sizes
- Keyboard shortcuts for power users
- Real-time node and edge updates
- Visual connection feedback with animated edges

## 🛠️ Tech Stack

- **React** 18.2.0
- **React Flow** 10.3.17 - Workflow canvas library
- **UUID** 9.0.0 - Unique ID generation
- **LocalStorage** - Data persistence
- **CSS3** - Custom styling (no external UI libraries)
